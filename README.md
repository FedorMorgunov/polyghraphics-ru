# Полиграфика — макеты интерфейса

Кликабельные макеты маркетплейса полиграфии: заказчик сам выбирает, **что** и **у кого** печатать, видит все цены и сроки, а цена финальная.

Стек самый простой: **HTML + CSS + чистый JavaScript**. Нет сборки, нет зависимостей, не нужен `npm install`.

## Как запустить

### Вариант 1. Просто открыть (10 секунд)

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP** на GitHub (или `git clone`).
2. Распакуйте архив.
3. Дважды кликните по **`index.html`**, и сайт откроется в браузере.

### Вариант 2. Через локальный сервер (рекомендуется)

Так надёжнее работает автоопределение города и кнопка «Поделиться расчётом».

```bash
git clone https://github.com/FedorMorgunov/polyghraphics-ru.git
cd polyghraphics-ru

# Python есть почти везде (macOS, Linux, Windows с Python):
python3 -m http.server 8000
# на Windows может быть: py -m http.server 8000
```

Откройте в браузере **http://localhost:8000**.

Если установлен Node.js, подойдёт и `npx serve .`.

### Вариант 3. Ссылка для команды (GitHub Pages)

1. На GitHub откройте **Settings → Pages**.
2. В **Source** выберите `Deploy from a branch`, ветку `main`, папку `/ (root)` и нажмите **Save**.
3. Через минуту сайт будет доступен по адресу `https://fedormorgunov.github.io/polyghraphics-ru/`.

## Что внутри

| Страница | Файл | Что показывает |
|---|---|---|
| Главная | `index.html` | Лого со слоганом, автоопределение города, поиск с подсказками, «Войти», «Стать партнёром», быстрый калькулятор с живыми ценами типографий, 14 плиток видов работ (включая «Дизайн»), сравнение исполнителей, «Почему мы?», FAQ |
| Калькулятор | `calculator.html` | Параметры по каждому виду работ, загрузка макета или заказ дизайна, срочность и доставка, **выбор исполнителя** (сортировка: оптимально / дешевле / быстрее / рейтинг), честная разбивка цены, ссылка на расчёт |
| Партнёрам | `partner.html` | Подключение типографий, дизайнеров и курьеров, форма заявки |

Как открыть нужный вид работ сразу: `calculator.html?type=cards`. Доступные значения: `design`, `cards`, `flyers`, `booklets`, `catalogs`, `posters`, `banners`, `stickers`, `blanks`, `calendars`. Для `packaging`, `merch`, `docs` и `outdoor` открывается форма индивидуального расчёта.

### Что можно потрогать

- **Город** определяется автоматически по IP. Если не получилось, ставится Москва. Город можно сменить вручную или определить по геопозиции. Выбор запоминается.
- **Поиск** понимает формы слов: «визитку», «баннер», «наклейки», «логотип».
- **Калькулятор** пересчитывает цены всех исполнителей при каждом изменении. Параметры сохраняются в адресе страницы, поэтому расчётом можно поделиться.
- **Вход**: маска телефона, подойдёт любой код из 4 цифр.

## Структура

```
index.html          главная
calculator.html     калькулятор и выбор исполнителя
partner.html        «Стать партнёром»
assets/
  css/style.css     все стили и дизайн-токены из бренд-бука
  js/data.js        иконки, виды работ, города, исполнители, формулы цен
  js/common.js      шапка, футер, город, вход, поиск (общие для всех страниц)
  js/home.js        логика главной
  js/calculator.js  логика калькулятора
  img/logo-mark.svg знак «Окно»
```

Чтобы поменять цены, виды работ или список типографий, правьте `assets/js/data.js`. Шапка и футер общие и лежат в `assets/js/common.js`.

## Дизайн

Всё сделано по бренд-буку «Визуальный код» v1.0:

- синий `#007AFF` — основной цвет, оранжевый `#FF9500` — только для главного действия (одна оранжевая кнопка на экран);
- шрифт Inter, скругления 8 / 12 / 20 / 28, линейные иконки 24 px со штрихом 1.8;
- метки реза как фирменная деталь.

### Слоган под логотипом

Сейчас стоит **«Все типографии — в одном окне»**. Он обыгрывает знак «Окно» и сразу говорит про выбор. Варианты на обсуждение:

1. «Все типографии — в одном окне» *(сейчас)*
2. «Выбираете вы — печатают лучшие»
3. «Сравни. Выбери. Напечатай.»
4. «От визитки до билборда» *(из бренд-бука)*
5. «Печать на ваших условиях»

Поменять можно в одном месте: константа `SLOGAN` в `assets/js/common.js`.

> Все цены, типографии, отзывы и цифры в макетах демонстрационные.
